# sachin.github.io

Personal portfolio site (plain HTML/CSS) deployed to Cloudflare.

- Static site lives in `public/` (entry point: `public/index.html`)
- Deploy config: `wrangler.jsonc`
- Deploy command: `npx wrangler deploy`

See [DEPLOYMENT.md](DEPLOYMENT.md) for the exact Cloudflare build settings and
why the build was failing.
